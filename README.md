# 🎟️ Curso Tickets - Laravel + React

Este proyecto está construido con Laravel en el backend y React (con Vite) en el frontend. Incluye rutas protegidas, tablas dinámicas, formularios y todo lo necesario para una app moderna.

---

## ✅ Requisitos

Antes de comenzar, asegurate de tener instalado:

- [PHP 8.1+](https://www.php.net/downloads.php)
- [Composer](https://getcomposer.org/)
- [Node.js (v16 o superior)](https://nodejs.org/)
- [NPM](https://www.npmjs.com/)
- [MySQL / MariaDB](https://www.mysql.com/)
- Un entorno local (como [XAMPP](https://www.apachefriends.org/es/index.html), Laragon o Valet)
